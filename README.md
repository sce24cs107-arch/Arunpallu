# Paradise Nursery

**Paradise Nursery – Online Plant Shop** is a React application for browsing plants and managing a shopping cart.

## Features
- Landing page with the Paradise Nursery name and a Get Started button
- About Us company information
- Plant product listing with prices and Add to Cart actions
- Shopping cart with remove and quantity-update controls
- Cart item count and subtotal
- Responsive styling

## Source files
- `src/AboutUs.jsx` – company information
- `src/App.css` – landing page and application styles, including hero background image
- `src/App.jsx` – main application and landing page
- `src/CartSlice.jsx` – `addItem()`, `removeItem()`, and `updateQuantity()` cart reducer functions
- `src/ProductList.jsx` – plant product listing
- `src/CartItem.jsx` – shopping cart item component

## Run the project
Place the `src` folder in a React + Vite JavaScript project, then run:

```bash
npm install
npm run dev
```

Project name: **Paradise Nursery – Online Plant Shop**
